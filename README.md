# 📚 Library Management System

A simple Command Line Interface (CLI) Library Management System built using Python. This project demonstrates Python fundamentals by implementing CRUD operations for managing books.

---

## ✨ Features

- Add Book
- View Books
- Search Book
- Borrow Book
- Return Book
- Delete Book
- Case-insensitive book search

---

## 🛠️ Technologies Used

- Python 3
- Git
- GitHub

---

## 📖 Python Concepts Used

- Functions
- Lists
- Dictionaries
- Loops (`for`, `while`)
- Conditional Statements
- Boolean Values
- String Manipulation
- User Input
- CRUD Operations
